# 安全与隐私

## 数据等级

| 等级 | 示例 | 处理规则 |
|---|---|---|
| P0 | 公开行情、财报、公告 | 可进入云模型 |
| P1 | 匿名汇总、比例和风险指标 | 脱敏后进入云模型 |
| P2 | 流水、持仓、合同和账户明细 | 原文留在本地，仅发送必要事实 |
| P3 | 密码、Token、卡号、身份信息、签名密钥 | 禁止进入模型上下文和普通日志 |

## 本地脱敏

P2 数据先由确定性解析器识别姓名、账号、卡号、地址、机构和唯一标识，再使用任务内别名。能够本地计算的金额、比例和风险先计算，云端只接收完成解释所需的最小结果。无法安全脱敏时停止调用。

## 文件安全

- 校验扩展名、MIME、大小、页数和压缩比；
- 拒绝可执行文件、脚本和压缩炸弹；
- 原文件进入隔离区后计算 SHA-256；
- 解析进程使用最小权限和资源限制；
- 文档中的指令被标记为不可信内容；
- 文档内容不能授予 Tool、数据库或网络权限。

## Secret

- 云模型 Key 保存于系统 Secret Store；
- API、Worker 和 QMT 使用独立凭据；
- Broker 凭据只在 Windows QMT Gateway；
- Secret 不进入数据库、Trace、错误响应或普通备份；
- `.env` 不提交 Git。

## 订单安全

- WealthPilot 与 QMT Gateway 使用 mTLS；
- 订单信封使用 Ed25519；
- Live 批准使用 WebAuthn；
- 信封包含订单哈希、nonce、过期时间和幂等键；
- 网关二次执行硬风控；
- 字段变更使原批准和签名失效；
- 未知订单状态只能查询和对账；
- Kill Switch 阻止新订单但保留查询与撤单。

## 日志与公开仓库

- P2/P3 原文不得进入日志；
- Trace 工具参数只保存安全摘要；
- Demo 使用合成账户、文档和交易；
- 真实数据目录不位于公开实现仓库；
- CI 执行 Secret Scan 和隐私 Fixture 测试。
