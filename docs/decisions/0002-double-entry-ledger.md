# 0002：财富底账采用双重记账

## 状态

Accepted

## 适用范围

流水导入、账户余额、资产负债、证券成交、退款、转账和对账。

## 最终决定

从第一阶段使用 `JournalEntry` 和 `Posting` 建立双重记账。已提交事项通过冲销和新分录修改，导入批次与源记录使用哈希和幂等键。

## Non-obvious rationale

多账户导入中的转账、信用卡还款、退款和券商资金变化会让简单流水表重复计算收入、支出或净资产；借贷平衡和对账可以在错误进入投资约束前发现漂移。

## 实现约束

- 每笔 JournalEntry 借贷总额相等；
- 已提交 Posting 不原地编辑；
- 资产负债表由账本和估值快照生成；
- 成交与资金变化进入同一账本。

## 验收方式

- Golden Fixture 平衡率 100%；
- 重复导入不产生重复分录；
- 转账不改变净收入；
- 所有修改可追踪至冲销链。
