# 用户体验

## 全局交互

Web/PWA 使用统一命令入口、全局通知中心和待审批队列。任何长任务在两秒内返回 Run ID 和首个进度事件；页面断开后可凭 Run ID 恢复。

所有研究页面固定展示：

- 数据截止时间；
- 资料覆盖度；
- 当前执行阶段；
- 风险和数据警告；
- 证据、成本和模型版本入口。

## 财富驾驶舱

首页按“需要用户采取行动”的顺序展示：

1. 现金缺口和逾期风险；
2. 财务目标偏离；
3. 组合和持仓风险；
4. 待审批事项；
5. 净资产与趋势；
6. Agent 建议和监控事件。

指标点击后展示公式、输入账户、估值时点和数据来源。

## 文件导入

```text
选择文件
→ 自动识别来源
→ 字段映射
→ 重复、退款和转账识别
→ 分类预览
→ 用户确认
→ 生成平衡分录
→ 账户对账
```

提交前显示新增、跳过、冲突和需要确认的记录。提交后只允许冲销。

## 文档与证据

文档中心采用三栏布局：左侧文档树，中间问答与比较，右侧原文。点击答案中的证据可以跳到页码和坐标高亮；点击表格结果可以查看行列、单位、期间和计算公式。

自动资料补全过程显示发现、下载、校验、解析、索引和质量检查状态。缺失资料不会被静默忽略。

## 股票研究

用户可以输入股票、同行比较条件、自然语言筛选条件或持仓问题。研究工作台显示 Agent 任务树，但只呈现结构化行为和产物。

Decision Memo 首屏固定回答：

- 当前判断；
- 个人是否适合；
- 公允价值区间；
- 最大建议仓位；
- 最强支持证据；
- 最强反方证据；
- 入场、退出和失效条件；
- 资料覆盖度与警告。

## 交易审批

订单审批页展示订单不可变摘要、Decision Memo、硬风控、持仓变化、最坏情景和过期时间。Live 订单必须完成 WebAuthn。订单字段变化后原批准立即失效。

## 主动服务

应用内通知保存完整内容。邮件只包含低敏摘要和本地应用链接。计划任务错过后只补跑一次，重复事件由幂等键抑制。
