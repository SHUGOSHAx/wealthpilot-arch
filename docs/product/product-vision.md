# 产品愿景

## 定位

WealthPilot 是专业个人财富管理管家团。它先理解用户的完整财务状况和人生目标，再组织财务、情报、投研、组合、风控和执行 Agent 提供持续服务。

## 用户价值

- 一个账本统一现金、存款、证券、基金、保险、房产和负债；
- 一个 Investment Policy Statement 统一财务目标与投资边界；
- 一个 Evidence Ledger 统一文档、行情、财务、新闻和结论；
- 一个 Portfolio Manager 统一个人适配性、证券研究和组合风险；
- 一个审计时间线统一建议、审批、交易、结果和改进。

## 产品承诺

1. 用户能解释每项资产、负债、现金流和投资建议来自哪里；
2. 所有关键数字可复算；
3. 所有投资结论有来源、截止时间、反方证据和失效条件；
4. 所有订单在执行前通过硬风控和用户批准；
5. 所有 Agent 改进经过离线评测、人工批准并可回滚。

## 成功标准

- 日常财务数据持续准确，不因多来源导入产生净资产漂移；
- 用户询问股票时，系统能主动补齐资料并生成可审计研究；
- 自然语言条件能够稳定转换为确定性筛选规则；
- 建议仓位同时满足现金流、目标资金和组合风险约束；
- Paper 与 Live 执行保持物理和权限隔离；
- Demo 用户可以在十分钟内完成从账单导入到模拟订单的完整流程。

## 产品边界

系统服务单个个人用户，A 股优先，覆盖股票、ETF 和基金。系统不提供自主实盘、高频交易、杠杆衍生品、自动报税、法律意见或绕过授权的内容获取。
